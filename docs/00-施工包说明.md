# 小组开工入口

新成员先看[项目首页](../README.md)，然后按顺序打开：

1. [24 项功能认领表](features/README.md)：选择功能，登记负责人和审核人。
2. 对应的 F01–F24 功能页：确认目标、已有基础、代码入口和验收点。
3. [协作指南](../CONTRIBUTING.md)：安装运行、分支、共享文件、PR 和交付规范。
4. [五周排期](04-功能排期.md) / [周日总结](weekly/README.md)：每周收束与依赖安排。

业务开发仍遵循 [CLAUDE.md](../CLAUDE.md) 与 [接口规格](01-接口规格.md)。不要重新 git init，不要把历史施工步骤当作当前功能状态。

[旧 AI 指令剧本](02-AI指令剧本.md)、[card-* 任务卡](cards/README.md)、[历史审核与台账](archive/README.md)作为参考保留。旧卡仍在实施的内容（如 card-24）先同步原实施者和最新台账，再关联到本轮功能。
