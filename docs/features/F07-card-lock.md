# F07 · 锁卡

## 本地实现（2026-10-11）

聊天“锁卡”“暂时锁定这张卡”“停用银行卡”或快捷场景“🔒 锁卡” → 选择本人已绑定正常卡 → 核对脱敏卡号与影响 → 模拟验证码 → 手动确认 → 显示已锁定。我的银行卡另有“临时锁卡”入口、“锁卡记录”页签；聊天“查看锁卡记录”可直达。非正常卡显示状态且按钮不可用。

锁卡选择与确认在右侧主内容区内联展示，不使用遮挡弹窗；打开面板时仍能查看余额、卡片详情和其他选项。已绑定卡号旁使用图标：正常卡为开锁，点击直接预览该卡；锁定卡为闭锁，点击验证是否允许自助解锁。图标跟随查询到的真实状态，点击图标不直接修改状态。挂失与冻结卡不可操作；本人临时锁定可按 F08 自助验证解锁，不经人工复核。

聊天“我找不到我的信用卡了”“银行卡不见了”先显示“临时锁定”和“挂失说明”，不自动执行任何写操作。挂失说明如实提示该办理尚未接通；确认遗失或被盗时使用发卡银行官方渠道。

复用 T12 `manage_card(lock)` 与 L2 确认机制，模拟验证码为 `123456`。预览绑定用户、会话与卡片，五分钟过期，服务重启失效；取消未执行预览使令牌失效，已执行锁卡不能撤销。同凭证重试幂等，错误验证码按用户持久限流，不能换会话绕过。状态写入前在事务内重读；状态变化与成功审计同时提交，审计失败回滚。

成功锁卡与解锁记录从审计持久化查询，最多显示最近一百条；重置聊天不会删除。密码、验证码与完整卡号不进入记录。锁卡不改变余额、授信或已有申请，也不取消订阅、冻结账户；已有额度工具拒绝锁定卡，当前账户转账不宣称停用。解锁属于 F08，本人临时锁定使用验证码自助恢复，无需人工复核。

验收：`tests/test_card_lock_flow.py`、`tests/test_card_lock_ui.py`，并回归既有卡片工具及全量验证。未修改冻结工具签名或核心数据库结构；只增加界面私有包装。
