## 共享文件怎么分工

每周开工在对应[周总结页](../weekly/README.md)指定集成人员，统一协调 `classifier.py`、`read_routes.py`、`write_flow.py`、`templates.py` 和共享数据模型。多人认领同一业务文件时，先约定改动范围和合并顺序。

功能负责人负责端到端交付，可以协调前端、编排与工具层人员，不把一个功能拆成无人负责整体验收的几段。
