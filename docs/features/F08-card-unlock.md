# F08 · 解锁

## 已批准的自助临时解锁（2026-10-16）

用户批准本人临时锁定的卡无需人工复核，且只验证模拟短信验证码（123456）。在银行卡列表点击卡号旁闭锁图标，图标右侧直接展开验证码输入栏及“确认解锁”，不再同时显示下方大面板；聊天“解锁银行卡”则保留右侧选卡流程。手动确认并验证成功后恢复正常。

新增私有 L2 自助能力，仅接受预览与成功审计 trace_id 精确对应的 F07 临时锁卡、本人已绑定卡，并检查关联账户正常；挂失、冻结或来源不明不允许自助恢复。五分钟预览绑定用户、会话和本次锁定事件；验证码失败按用户持久限流，重复请求幂等，状态变更与审计同事务提交。旧版缺少精确关联的锁定不自动推断来源或降级解锁；来源不明的小锁禁用并说明原因。用户确认尾号5123及1111的历史来源不确定，因此不迁移或修改这两张卡的状态。

通用 T12 `manage_card(unlock)` 继续保留以下原有 L3 契约；它与本段受限的自助临时解锁是不同能力。以下历史验收点中的 L3、延迟及人工复核不适用于已批准的自助临时解锁路径。
