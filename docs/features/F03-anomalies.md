## 本轮验收（2026-10-21，F03 回执收口）

**改动范围**：只在“回执”这一层做文章 —— 四条规则与阈值**一行没动**（判定仍是 `main` 的冻结口径）。

| 文件 | 改了什么 |
|---|---|
| `tools/_query_analysis.py` | `_anomalies` 的每条命中多带 `ts` / `counterparty`（**流水行原值照抄**），只进 facts |
| `tools/query.py` | T4 的 `facts["items"]` 透出这两项；`data` 契约仍是 §2 冻结的 `txn_id/reason/severity` 三键 |
| `agent/render_lists.py` | 新增 `anomaly_line` / `render_anomalies`（汇总句 + 每条命中一行；空结果有独立句子） |

| `app/cli.py` | 离线替身的两条取词修正（见下“顺手修的两个坑”） |
| `tests/test_anomaly_wording.py`（新） | 12 条回执用例；`tests/cases/orchestrator.yaml` 补 bill-009；`tests/test_cli.py` 补 2 条替身用例 |

**为什么金额不取绝对值**：命中都是支出，`amount_yuan` 自带负号（`-1,546.00 元`），所以明细行说“金额 …”
而不说“支出 …”—— 渲染层**不许换算**（取绝对值就是把 facts 的数字自己改一道），宁可用中性措辞配带符号的原值，
也不造“支出 -1,546.00 元”这种双重否定。

### 顺手修的两个坑（都是实测撞出来的，不是凑数）

1. **问异常、答环比**：离线替身的规则表“先匹配的赢”，而 F03 的原话「上个月有什么异常支出」同时含“异常”与“支出”，
   被账单分析抢走（实测回执：`2026-08 共支出 9,152.00 元，环比 -32%`）。把「异常」排到账单分析**之前**
   （照 F10「测评」排在「理财」之前的既定道理：具体意图优先）。
2. **上上个月答成上个月**：相对时间词 `next()` 按表顺序取，子串「上个月」先命中。改成**按长度降序**取词。

### 剩余限制（诚实写在这里）

- **本轮没碰四条规则与阈值**：金额偏离 / 凌晨 / 短时高频 / 陌生商户的实现与边界（恰好 3 倍不算、3 倍多 1 分才算）
  沿用 `main` 的冻结口径，回归仍在 `tests/test_query_analysis.py`；本轮新增的用例只盯**回执措辞**。
- 明细行的严重程度只会出现 `关注` / `高危`：工具层按“命中 1 条 = medium、≥2 条 = high”判定，
  `SEVERITY_CN` 里的 `low` 是表内保留值（表外值原样透传，不猜）。
- **失败路径那条用的是工具层入口**：非法账期（`去年` / `2026-13`）在编排层会被缺槽 CLARIFY 拦在前头
  （替身只给相对时间词，字面上造不出一个能透传给工具的非法账期），所以那条演示直接打工具函数。
- **没截图**：本机没有浏览器自动化依赖，项目红线又是“引入新依赖前先问” —— 改用上面的**可复现命令 + 真实输出**留证，
  验收清单里“保留截图或可复现命令”取的是后者。
