# F09 · 挂失

## 2026-10-24 本地实现

已按用户确认实现“临时锁卡 + 挂失并补卡”两条路径，不另设临时挂失。暂时找不到卡推荐原有临时锁卡；明确遗失并补卡直达向导；“帮我挂失”先选择办理方式。两种操作均有详细办理须知。

正式办理仅支持本人已绑定、正常或锁定的借记卡；信用卡、冻结卡、已挂失卡说明原因。右侧内联向导展示脱敏客户与卡号、产品、模拟费用及办理时间、可选模拟领取网点、地址电话营业时间、预留手机号。阅读确认、下一步、返回及关闭未提交表单不执行挂失。

模拟银行卡密码及验证码验证通过，用户明确提交后进入 L3 六十秒可撤销窗口；到期原卡变为 lost，同时受理补卡申请，标记待模拟审核。后台结算独立于记录页面，应用停止期间不保证准时执行，重启恢复持久申请。原卡挂失不可自助解锁；补卡不代表已制卡、寄送、激活或发行新卡。仅卡片级限制，不冻结关联账户资金、不改变余额、不自动取消已有订阅，也不拦截独立账户转账。

新增私有申请表，核心卡状态枚举及 T12 契约不变。用户与会话绑定预览，验证失败按用户持久限流；同用户重启后可查询及撤销本人窗口内申请。事务内重查所有权、绑定及原状态，挂失、申请受理、成功审计原子提交；重复提交幂等。凭证不进入聊天、日志、数据库或回执。
