# 演示指南 · 转账域 v2（收款人三态 · 标签 · 同音 · 专属额度 · 黑名单）

> 对象：2026 FinTechathon 演示/评审。**全程自然语言，无脚本切换**。
> 固定验证码：**123456**。所有数字来自工具层事实包，可直接对着回执逐行讲。

---

## 0. 启动（评测环境一条命令）

```bash
uv sync
uv run python -m data.seed --reset          # 重建合成库（5 位收款人、600 笔流水）
uv run streamlit run interfaces/web/app.py  # 打开 http://localhost:8501
```

- 需要真实模型时确保目录里有 `.env`（worktree 不会自动带，`Copy-Item repo\.env .`）。
- 网页左侧四个页面：聊天 / 账单图表 / 审计时间轴 / 银行卡。

## 1. 开场：收款人是主数据（30 秒）

> 「我的收款人有哪些」

- 回执 = **一张表格**（收款人 / 手机号 / 银行 / 白名单列）+ 表下说明
  「白名单：专属额度内转账免验证码（超额度仍需验证码）」+ **卡片操作区**。
- 讲：**每个收款人有三态** —— 白名单（额度内免码）/ 普通（要码）/ 黑名单（转账送礼全拒），
  下面所有功能对同一个人给同一套结论。

---

## 2. 标签指代（30 秒）

> 「给我妈转 200 元」

- 确认卡收款人 = **张小美**（标签「妈妈」命中）→ L2（非白名单）要验证码。
- 「确认」→ 输 **123456** → 转账成功。

## 3. 同音匹配（30 秒）

> 「加个收款人，叫王晓虹，手机号 138****9001」
> 「给王筱虹转 100 元」

- 「王筱虹」按**拼音全等**命中「王晓虹」（pypinyin，同音误写容错）。
- L2 确认卡 → 可就此打住（不必真转）。

## 4. 白名单额度内免码 —— **深夜也成立**（45 秒，本轮的亮点）

> 「给房东转 100 元」

- 收款人 = **王五**（标签「房东」命中），**L1 免验证码**。
- 若演示在深夜（23:00–06:00），风险提示会写
  「夜间时段转账；**白名单专属额度内，深夜时段也免验证码**」—— 直接点确认即执行。
- 对比句：`给我妈转 200 元` 在深夜 → **L3 人工复核**（夜间 + 首次收款），
  说明普通人的深夜风控**照旧生效**，白名单不是"关风控"。

## 5. 超额度 / 未设额度要码（45 秒）

> 「加个收款人，叫张小刚，手机号 138****9002」
> 「把张小刚加入白名单」→ 确认 → 123456（加白本身 L2+验证码：授予特权必须验身份）
> 「给张小刚转 50 元」→ **L2**「该白名单收款人未设专属额度，转账需要验证码」

- 讲：免码**只在专属额度内**，额度/未设额度都要码 —— 额度是防"一次免码、永久免码"的闸。

## 6. 黑名单闭环（60 秒，本轮的第二个亮点）

> 「把张小美拉黑」→ 确认（L1，加黑不用验证码）
> 「给张小美转 100 元」→ **FORBIDDEN**「已在黑名单，不能转账或送礼」
> 「给张小美送生日礼物，预算 100 元」→ **FORBIDDEN**（黑名单同时管转账与送礼）
> 「把张小美移出黑名单」→ 确认 → **123456**（解除黑名单必须验证码）→ 已解除

## 7. AA：含非白名单要码（30 秒）

> 「向王五和赵六 AA 收款 300 元」

- 确认卡 **L2**：「含非白名单收款人（赵六），需要验证码」—— 发起人验一次，不是每人一次。
- 确认 → 123456 → 已发起（措辞只说"已发起"，不说"已收款"）。

## 8. 定时转账同口径（30 秒）

> 「2026-10-30 给房东转 100 元」

- 定时确认卡多一行「预约时间」、不印「预计到账」；同一套解析/额度（房东→王五）。
- 确认 → 预约成功、**不扣款**（执行只落预约）。

## 9. 行内按钮（15 秒）

- 回到收款人卡，点「转账」「加白」「拉黑」「解除」任意一个 ——
  按钮 = 替你说一句完整的话，走**同一条**流水线（不是绕过风控直接改库）。

## 10. 收尾：审计时间轴

- 切到「审计时间轴」页：每一步都有 trace_id / 意图 / 工具调用，展示可回溯性。

## 备用的两个"翻车保险"

| 情况 | 处置 |
|---|---|
| 演示库被前面的人弄脏 | `uv run python -m data.seed --reset` 一键复原 |
| 会话串味 | 网页侧栏「重置会话态」按钮 |
| 深夜演示 | 无需处置 —— 白名单额度内免码已覆盖深夜因子（round2） |
