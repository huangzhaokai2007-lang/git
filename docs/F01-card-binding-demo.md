# 模拟银行卡绑定演示

此功能使用本地合成银行卡，无真实银行连接。银行卡密码是下表中的模拟密码。账户余额来自现有演示库；交易等操作可使余额变化，绑卡不会改余额。

## 启动

在 D 盘仓库运行 PowerShell：

```powershell
.\scripts\start-card-binding.ps1
```

浏览器打开 http://127.0.0.1:8501 ，选择“我的银行卡”。启动脚本把依赖缓存、Python 下载、临时文件和独立演示数据库放到 D 盘项目目录，不覆盖既有 var/bank.db。

## 预设演示卡

| 模拟完整卡号 | 模拟银行卡密码 | 卡类型 | 初始状态 |
| --- | --- | --- | --- |
| 6222000000000001 | 314159 | 储蓄卡 | 正常 |
| 6222000000000002 | 271828 | 信用卡 | 正常 |
| 6222000000000003 | 161803 | 储蓄卡 | 已挂失 |

这些是公开的合成测试夹具，仅供演示。第一张与第三张卡关联同一储蓄账户，因此余额相同。信用卡账户余额可能为负，授信额度在详情中单独显示。

## 演示步骤

1. 初始列表提示尚未绑卡。点击“绑定银行卡”，在表单输入第一张卡号及对应密码，点击“验证银行卡”。
2. 预览仅显示脱敏卡号，尚未写入绑定记录；点击“确认绑定”完成绑定。取消则不绑定。
3. 列表按“卡号、状态、余额”三列展示。余额默认星号，右侧眼睛按钮显示或隐藏该行余额。
4. 点击卡号，聊天追加脱敏详情；详情区域的余额默认隐藏。
5. 点击“查看完整卡号”，重新输入该卡密码，验证成功后在临时区域显示完整模拟卡号。点击“收起完整卡号”恢复隐藏。
6. 再次绑定同一卡只提示已绑定。试错密码或不存在卡号不会新增绑定；连续五次失败暂停该卡验证五分钟。
7. 重置会话态，卡号与余额展示状态恢复隐藏，已完成绑定仍保存在数据库中。

## 代码与兼容范围

新增工具和独立绑定表不会改变原 T18 list_cards 的签名、字段或默认归属查询语义。Web 查询卡片时使用已绑定卡片；原 CLI/API/IM 的 T18 查询保持原行为。当前没有解绑入口，也没有新增全局用户登录系统。

绑卡与详情操作使用确定性代码，不需要模型服务。聊天输入“卡片查询”“我的银行卡”“我有哪些银行卡”等明确清单指令，也可在没有模型密钥时直接进入已绑定卡片列表。复杂自然语言查询仍依赖现有分类器；明确指令有模型不可用的真实回归测试，其他意图测试使用替身。

聊天输入“卡片绑定”“绑定银行卡”“我要绑卡”等明确指令，会直接打开已有绑卡表单；仍须输入预设凭证、验证并确认，聊天指令本身不会保存绑定。“我想申请一张信用卡”等表达会明确提示当前不支持新信用卡申请或审批，并提供预设模拟卡的绑定表单。

同一入口还支持常见自然表达：查询如“帮我看看我的银行卡”“我绑定了哪些卡”；绑卡如“添加一张银行卡”“我有张卡，想绑定”“我想把这张银行卡绑定一下”；申请说明如“我要办信用卡”“信用卡怎么申请”。支持礼貌词、空格和常见语气词，但只匹配完整请求；否定、解绑、挂失、冻结和混合操作仍交由原分类器处理，不自动绑定或申请新卡。未覆盖的复杂表达仍需模型分类。

完整卡号、密码及明文余额不进入默认绑卡回执。密码哈希存于补充表；完整合成卡号存于补充凭证表。若在聊天粘贴卡号或密码，Web 入口先遮蔽并引导使用表单，不把凭证发送给模型。
