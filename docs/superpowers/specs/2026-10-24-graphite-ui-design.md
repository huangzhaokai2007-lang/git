# 石墨深色 UI 视觉迭代

用户提供十三张参考截图，并已确认：统一深色方案、侧栏单列图标文字、主区保留聊天与内联办理。

## 参考分析

参考图常见大面积底色为 RGB(8,9,10)、(20,21,22)、(22,23,24)，用接近的深灰形成空间层次。主要文字为灰白，次要文字降低明度；少量紫色用于主要操作和焦点。细描边、轻阴影、适度圆角，列表比卡片更紧凑。部分截图带宣传展示渐暗效果，实际应用不能照搬为低对比度正文。

## 视觉规格

- 背景 #0B0C0E；侧栏 #101113；表面 #151618；抬升表面 #1C1D21；描边 #2C2D33。
- 标题 #ECEEF2；正文 #D1D4DC；次级 #A1A5AF。主要操作紫色 #6667C9，白色文字；状态使用低饱和绿、黄、红并保留文字标签。
- 使用本机 Segoe UI / 微软雅黑 / system-ui，不下载字体。主标题 26–28px、区块标题 18–20px、正文 15px、标签 13–14px、辅助文字 12–13px；段落行高 1.6。
- 八像素间距体系，桌面侧栏约 272px，主内容最大宽度 1120px；窄屏保留侧栏开关、字段换行和可横向滚动的表格。
- 按钮 8px 圆角，表单/消息 12px，业务容器 16px；1px 低对比描边，低透明阴影。选择、悬停、键盘焦点、禁用态各自清晰。
- 快捷场景改为单列 Material 线性图标与中文名称，指令和键保持既有映射。新增激活状态仅表达当前快捷入口，不伪装业务成功。
- 银行卡使用深石墨与暗紫灰区分类型，保留金属芯片、脱敏卡号、选择/浮动动效及真实状态驱动的锁链动画。
- 聊天、输入栏、提示、确认、锁卡、额度、挂失补卡、记录及收款人卡片统一配色。业务说明、数字、权限与验证步骤不改变。

## 实现与验证边界

新建集中主题 CSS 和原生 Streamlit 深色配置，适配现有组件样式。没有新依赖、远程字体或下载；保留当前分支、数据库与业务契约。先更新功能测试中的呈现标签并观察失败，再实现图标布局；运行既有 UI、分层、安全及完整验收。浏览器检查桌面、窄屏及确认表单，保存截图，并检查文字对比度和可见焦点。
