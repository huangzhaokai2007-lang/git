# F18 订阅提醒行为设计

W1 要求「莫在 10-04 前提交 F18 的提醒触发、渠道、去重与取消方案」（`docs/04-功能排期.md`）。本文定这四件行为与契约影响，**不含代码实现**。

## 背景：为什么 W1 只定方案不写代码

`subscription_remind` 是「意图在、工具不存在」的孤儿：`docs/01-接口规格.md` §3 意图清单列了它，§2 工具表却没有对应工具（该表标题写明「18 个，名字与字段名冻结」）。`agent/classifier.py:60` 已显式标注「§3 有此意图、§2 无对应工具 → 留空待定」，`board/ledger.md:1663` 把它列入「另议 2」。接通它必须新增工具，而新增工具要人类改规格并注明 `SPEC-CHANGE` 后通知全员（`docs/01-接口规格.md` 开头第 3–4 行）。

- 时间基准用 `data.seed.AS_OF`（= 2026-09-12）而非 `datetime.now()`，与 `tools/subscription.py` 僵尸窗口口径一致，保证跨天可复现、测试可钉死。

## 触发：以 next_charge_date 为锚，提前 3 天

订阅表已有 `next_charge_date`（`data/schema.sql:29`），是唯一可靠的「下次扣费」信号，不新增字段。

| 场景 | 处理 |
|---|---|
| 距今 > 3 天 | 不提醒 |
| 距今 = 3 天 | 提醒（闭区间下界） |
| 距今 = 0 天 | 提醒，措辞改「今天扣费」 |
| 已过期（早于 AS_OF） | 不提醒，且不顺延（顺延是另一次业务决策，不在 F18 范围） |
| 年费订阅（`cycle=yearly`） | 同样适用 3 天窗口，不因周期长而放宽 |

建议取统一 3 天而非「月费 3 / 年费 7」分档：少一个分支即少一处口径漂移。**待队长确认。**

## 渠道：本期只做查询展示，不做主动推送

用户问「在会员下次扣费前提醒我」时，编排层识别意图 → 复用 F19 已有的 `list_subscriptions` 取事实包 → 筛出落在 3 天窗口内的订阅 → 模板回执。

- 主动推送需要定时任务、消息通道、投递回执与失败重试。`scripts/` 下无任何调度器，上推送等于给 W4 塞进一整套基础设施，而 F18 在 W4 仅一格，交付风险不可控。
- 查询展示可完全复用 F04 已打好的地基（读路由 + 模板渲染），零新增基础设施。
- 窗口外的订阅建议不列。列了就是「订阅列表」而非「提醒」，与 F19 职责重叠。**待队长确认。**

## 去重：不做持久化，故只做会话内与回执内去重

本期不新增表、不新增字段。提醒内容由 `next_charge_date` 实时推导，无额外状态需记住。一旦持久化会立刻引入「记录存哪张表、已读未读怎么算、用户改扣费日如何同步」等不在 F18 范围的问题，而涉及 DDL 即属规格冻结，需 `SPEC-CHANGE`。

- 因本期是「用户主动问才答」，不存在骚扰用户的问题，跨会话去重非必要。
- 回执内按 `sub_id` 去重，避免数据侧重复行造成重复展示。
- 跨会话去重的缺口如实登记为剩余限制，写进交付说明。

## 取消：复用 F04 已接通的 subscription_cancel

提醒回执展示商户名后，用户说「把云端网盘取消了吧」即走既有四步写流程，不新增任何入口。回执里的商户名必须与 `agent/write_intents.py` 的 `_shape_subscription` 口径对齐（按 `merchant` 唯一命中补 `sub_id`），否则用户复述商户名可能匹配不上。

## 契约影响：建议新增 T19（待审批）

```
T19  remind_subscription(as_of=None)
     入参：as_of 可选（默认取 AS_OF，供测试钉死时间）
     data：items[{sub_id, merchant, amount, cycle, next_charge_date, days_left}]
     权限档：L0（只读）；复用 T10 事实来源，不新增表与字段
```

- 替代方案是编排层复用 `list_subscriptions` 后自行筛选窗口，零契约变更，但会让「提前 3 天」这个业务口径落在编排层。按仓库铁律业务数字须来自工具层事实包，故建议新增 T19。
- 走流程步骤：人类修改 `docs/01-接口规格.md`（§2 标题 18 → 19、补 T19 行）→ commit 注明 `SPEC-CHANGE` → 通知全员 → 才可写代码。**审批完成前 F18 不动代码。**
