# F07 锁卡内联展示与逐卡图标

用户已指定并授权布局：锁卡选择、确认与结果放在右侧主内容区，卡号旁提供状态图标，可同时操作余额与详情。

实现范围：保留已有预览、验证码、手动确认和审计流程；正常卡图标开锁，点击预览指定卡，提交后图标闭锁。非正常卡禁用，解锁的 F08 验证复核机制不在本轮新增。切换目标卡先取消旧的未执行预览。

执行与验收：

- 新增真实 Streamlit 交互用例，验证聊天锁卡无 dialog、卡号图标进入确认、同时操作余额与详情后仍锁定正确卡、状态变化后图标更新。
- 移除锁卡 dialog，改用带边框的内联容器；卡号列并排显示卡号与锁图标，传入当前会话。
- 运行相关 UI 回归与 scripts/verify.sh，在数据库副本上进行浏览器检查；用户原始演示数据不作锁卡操作。
