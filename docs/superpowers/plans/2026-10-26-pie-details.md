# 饼图分类明细实现计划

用户指定：点击扇形后，在图正下方展开该分类账单；框内显示约四五条，可上下滚动。

实现采用按需读取，不预先加载所有历史图的流水。扇形及图例均可通过鼠标和键盘选择，再选同类或点击收起关闭；新分类替换旧明细。每个回复独立保存选择，读取原回复的账期与分组口径，不继承当前聊天筛选或未提交业务。

- [x] 工具私有读取复用现有归属、账期和金额格式化内核，不改冻结公共工具签名。仅返回本人该账期、该分类的支出；完整列表不截断。
- [x] 编排桥校验分类属于原图，记录来源 trace 和点击查询审计；保留业务草稿、OTP 及聊天上下文。
- [x] Streamlit 组件状态触发按需读取，结果缓存只用于当前回复；同次重绘不重复查询。
- [x] 组件在图下显示紧凑列表，约 260px 高；小屏保留横向文字，框内滚动到边缘允许页面接续滚动。
- [x] 验证分类/账期/用户隔离、年度及空结果、审计、草稿不变、键盘与切换、重复渲染及安全文本。执行相关测试、完整验收与浏览器检查。
