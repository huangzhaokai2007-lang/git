# F07 锁卡实施方案

用户已批准快捷且严谨的模拟锁卡流程，沿用 F01 已绑定卡与 T12 锁卡工具。

1. 新增私有工具包装：仅本人已绑定正常卡可预览；确认令牌绑定用户、会话、卡片，五分钟过期；错误验证码持久限流；取消撤销令牌；复用 T12 状态变更和事务审计及幂等结果。预览仅内存保存，服务重启后失效。
2. 新增 agent 入口：明确锁卡语句、锁卡咨询打开选卡窗口，否定/解锁/挂失不误操作；数字凭证仍由 F01 保护。
3. 新增对话框：选择脱敏卡号、说明影响、模拟验证码及手动确认、结果、记录入口；左侧快捷锁卡和银行卡页面入口；银行卡页面增加锁卡记录页签。
4. 已锁定/挂失/冻结卡展示原因，不能继续执行；结果刷新卡片列表，不改余额或订阅状态。仅设置卡状态并限制已有卡片额度操作，不宣称账户转账或订阅扣费已停止。
5. 先写真实数据库和 Streamlit 行为测试，再实现；覆盖错误 OTP、取消、超时、跨用户/会话、重复提交、状态变化、记录持久化、审计失败回滚。
6. 验证全量 pytest 与 scripts/verify.sh，独立代码审核、网页截图，提交本地，不自动推送或合并主分支。密钥不进入提交；保留演示数据库已有绑定/申请记录。
