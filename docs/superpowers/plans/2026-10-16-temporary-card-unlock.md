# 临时锁卡入口与自助解锁

用户已明确批准：找不到卡时先提供临时锁定选项；本人临时锁定的卡解锁不经人工复核。

范围：右侧内联展示“临时锁定”“挂失说明”，不执行尚未接通的挂失业务。按用户最新要求，银行卡列表直接在小锁右侧显示短信验证码与确认按钮，锁卡及解锁均不另开下方大面板、不再要求银行卡密码；保留预览、限流、会话与用户绑定、幂等和原子审计。

通用 T12 unlock 的冻结签名、L3 返回契约及原有复核机制保留。新增私有 L2 自助解锁能力，仅接受本人已绑定、关联账户正常、且持久化审计证明为 F07 临时锁卡流程锁定的卡；来源不明、挂失、风控冻结拒绝。预览保存锁定事件编号，防止一次解锁后重新锁卡时旧预览仍可使用。密码与验证码不进 LLM、聊天或审计。

步骤：先补缺失入口与解锁安全用例并确认失败；实现数据来源校验、私有工具、agent 包装和内联界面；回归原有锁卡与 F01/F06；运行完整 verify.sh、独立安全复核与副本浏览器验收。用户原始演示卡片状态不用于测试写入。
