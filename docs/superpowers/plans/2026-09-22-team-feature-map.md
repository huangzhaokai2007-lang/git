# 小组协作入口整理实施计划

**Goal:** 让组员从首页直接找到自己的功能、代码入口和交付要求。

**Architecture:** 原有五层代码目录保持不变；首页导航到 24 个功能任务页。认领表集中登记进度，旧资料保留为参考。

**Tech Stack:** Markdown、GitHub Issue/PR 模板；不增加运行依赖。

- [ ] 归档原 README，重写精简首页；更新施工包入口与排期文档。
- [ ] 建立 docs/features/ 下的 F01–F24 说明及唯一认领表，逐项核对意图、工具、源码、既有测试、依赖和验收点。
- [ ] 编写 CONTRIBUTING.md、功能认领/周总结 Issue 模板、PR 模板、五次周日总结页，标注旧看板和旧任务卡用途。
- [ ] 检查编号、周分布、日期、链接、模板与源码一致性；确认业务源码和冻结规格不变。
- [ ] 执行 uv run pytest -q 与 bash scripts/verify.sh，独立审阅后修正问题。
- [ ] 提交独立分支，创建并附上 GitHub PR；不自动合并 main。
