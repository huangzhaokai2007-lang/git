# 历史资料与技术参考

[返回首页](../../README.md) · [当前 24 项功能](../features/README.md)

本轮使用 F01–F24 组织业务功能。下面的 card-* 是旧施工步骤，可能包含历史状态、过时数量或已被后续决定覆盖的要求；不能直接当作本轮进度。原文件路径保持不变，已有脚本引用不受影响。

| 资料 | 用途 |
|---|---|
| [整理前 README](README-before-collaboration.md) | 原技术长文、架构解释与演示记录快照 |
| [旧任务卡](../cards/README.md) | 历史施工步骤；card-24 的订阅取消对应本轮 F04 |
| [AI 指令剧本](../02-AI指令剧本.md) | 旧开发提示与任务要求 |
| [开发台账](../../board/ledger.md) | 历次决策、审核和限制；接手旧卡先查最新记录 |
| [审核记录](../../board/reviews/) | 历史代码审阅证据 |
| [旧进度看板](../../board/progress.html) | 历史快照，不是当前看板 |
| [答辩提纲](../答辩提纲.md) | 技术讲解参考，演示前重新核对当前能力 |
| [旧 AI 角色说明](../../agents/) | 原开发流程说明，区别于业务编排目录 agent/ |

当前契约仍以[接口规格](../01-接口规格.md)和[项目约束](../../CLAUDE.md)为准，发现差异先登记并由队长确认修订。
