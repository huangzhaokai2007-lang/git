# 02 · AI 施工指令剧本（照抄即可）

> 用法：打开仓库根目录 → `claude` → 把每张卡的【指令】整段粘贴。
> 一次只给一张卡。AI 说"完成"后，你只做三件事：跑【验收】、看 diff、commit。
> 全程 19 张卡，对应 6 周。每天 1–2 张卡是正常节奏。

---

## 0. 怎么用：四条规矩先说清

1. **先粘贴"元指令"再干活**（见第四节），让 AI 每次都先读 `CLAUDE.md` 和 `docs/01-接口规格.md`。
2. **一次一张卡**，不给 AI 超过 1 天的活。想把 3 个场景一次做完 = 一定翻车。
3. **AI 说"完成"不算完成**，`bash scripts/verify.sh` 过了才算。
4. **每张卡一个 commit**：`git commit -am "card-07: 理财与跨场景工具"`。坏了 30 秒回滚。

### 万能指令模板（自己拆卡时套这个）

```
【任务卡 #__】<一句话目标>

第一步：读 CLAUDE.md 和 docs/01-接口规格.md，读完先用 5 行复述你理解的约束，等我确认再动手。
范围：只允许改 <文件/目录>，其他文件一律不动。
接口：函数名、参数名、返回字段严格按规格，不得重命名或增删字段。
要求：<3-5 条>
禁止：<禁止项>
交付：
1) 代码 + 单测
2) 运行 `uv run pytest -q && bash scripts/verify.sh`，把真实输出贴出来；没跑通不许说"完成"
3) 3 行以内说明：改了什么 / 什么没做 / 有什么风险
```

### 卡 00 · 项目骨架与可运行空壳
```
【任务卡 #00】初始化可运行的项目骨架
```

## 9. 千万不要交给 AI 的 5 件事

1. **接口设计定稿** —— 只能人定。AI 定接口 = 六周后你会在一堆不一致的字段名里挣扎。
2. **金融业务规则** —— 限额、风险等级、可撤销窗口、合规文案，逐条人工核对。AI 会给你"看起来合理"的错规则。
3. **演示剧本和讲稿** —— 评委听的是人的判断力，AI 写的稿子是 AI 味的。
4. **验收判断** —— 不能不跑就说"AI 说过了"。这是唯一能防住"AI 假装完成"的手段。
5. **赛题解读与取舍** —— 场景选择、砍掉什么、押注哪个创意点，是人的决定。

## 10. 常见翻车与补救

| 症状 | 原因 | 补救 |
|---|---|---|
| AI 说完成，跑起来报错 | 没让它贴真实输出 | 追加："贴出 `bash scripts/verify.sh` 的真实输出；如果没跑过，现在跑" |
| 改了三张卡后到处是 bug | 一次给太多 + 上下文污染 | 停下，`git log` 回滚到最后一次全绿的 commit，重新一张一张来 |
| 字段名被悄悄改了 | 没强调接口冻结 | 元指令 B 找偏差，改回规格；把偏差写进 CLAUDE.md 禁止项 |
| 上下文超 70% 后开始瞎编 | 单会话跑太久 | `/compact` 或 `/clear` 开新会话，从 CLAUDE.md 重新起 |
| 测试"通过"但其实没测 | AI 改了测试 | 元指令 B；review diff 时专门看 `tests/` 的改动 |
| 演示当天断网 / API 挂了 | 没有降级 | 卡 19 的离线回放模式必须做 |
| 6 个场景都做了一半 | 贪多 | 砍到 3 个做透，剩下 2 个只留演示级入口 |
