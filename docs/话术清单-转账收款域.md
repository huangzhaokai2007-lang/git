# 话术清单 · 转账 / 收款人 / 预约 / 群收款

> 面向演示与验收：**说这句话会发生什么**。
> 每条都对着**真实分类器**跑过（37/37 全部命中意图，见 `scripts/verify_phrases.py`）。
> 送礼（`gift_plan`）在**网页端已下线**（`agent/web_features.py` 主动移除），本清单不含。

---

## 0. 通用规则（先说清，演示不翻车）

| 规则 | 说明 |
|---|---|
| 人名可以是**姓名 / 标签 / 拼音 / 同音** | `王五`、`房东`（标签）、`wangwu` 都认 |
| **同名**会出「解析卡」 | 种子里有两个李四 → 让你点选（5 分钟有效） |
| 金额、时间**能在卡面上改** | 卡下方有输入框 + 「按修改重新预检」 |
| 验证码固定 **123456** | 3 次错锁定本次会话 |
| 档位 | 白名单额度内 **L1 免码** · 非白名单 **L2 要码** · 深夜+首次 **L3 待人工复核（60s 可撤）** |
| 限额 | 单笔 **500 元**（白名单额度内豁免）· 日累计 **2000 元** |
| 白名单 | 必须带 **额度 + 有效期**（缺了会追问；有效期用**日历**选） |

## 1. 单笔转账 `transfer_single`

| 说这句 | 结果 |
|---|---|
| `给王五转 100 元` | 确认卡（L2 要码；白名单内则 L1） |
| `给王五转一百块` | 同上（中文数字也认） |
| `转 50 给李四` | 语序反过来也认 |
| `给房东转 300` | **标签**指代（王五的标签是房东） |
| `给wangwu转 50` | 拼音 |
| `转给赵六 66 元` | 普通收款人 → L2 |
| `给王五转 1000 元` | 走白名单额度（1000/月）→ 免码；超额度则要码 |
| `给王五转 5000 元` | ❌ 超单笔上限 500（白名单额度内才豁免） |

演示要点：同一句换不同指代（姓名/标签/拼音），回执里都是同一笔 → 证明**解析统一**。

## 2. 预约转账 `transfer_scheduled`

| 说这句 | 槽位 |
|---|---|
| `明天给王五转 200 元` | schedule=明天 |
| `下周一给房东转 500` | schedule=下周一 |
| `2027-10-10 给王五转 100 元` | 绝对日期（`2027.10.10`、`2027年10月10日` 也认） |
| `每个月末给房东转 500 元，到年底` | repeat=每个月末 + repeat_until=年底（**月末对齐**：10-31 → 11-30 → 12-31） |
| `每月 15 号给张小美转 300` | repeat=每月 15 号 |

预约相关操作：

| 说这句 | 结果 |
|---|---|
| `我的预约有哪些` | 列表（时间/收款人/金额/状态/**循环列**） |
| `把预约改到后天上午` | 改时间（也可以点卡面「改某笔预约的时间」用**日历+时刻**选） |
| `现在就把那笔预约执行了` | 立即执行 |
| `取消明天那笔预约` | 取消（不扣款） |

## 3. 收款人 `payee_*`

| 说这句 | 结果 |
|---|---|
| `我的收款人有哪些` | 列表卡：头像/姓名/脱敏号/银行/类型徽章 + 统计 + 筛选 + ▸ 展开 |
| `我有几个收款人` | 同上 |
| `把张小美加入白名单，额度 500 元，有效期到 2026-12-31` | 白名单确认卡（L2 要码） |
| `把王五加入白名单` | 追问**额度 + 有效期**（两项必填） |
| `把张小美的专属额度改成 800 元` | 改额度（要码） |
| `把王五移出白名单` | 移出（要码） |
| `把赵六拉黑` | 拉黑（同时清掉白名单） |
| `把赵六移出黑名单` | 解除黑名单 |
| `删除收款人赵六` | 删除（要码） |
| `给张小美加个备注：老同学别转错` | 备注 |
| `给王五加标签：房东` | 标签（之后可用「房东」指代他） |
| `给张小美记一下卡号 6222000000000001` | 只存后四位 |

卡面操作：展开某人后可 **转账 / 加白名单·移出白名单 / 拉黑·解除黑名单 / 删除**，
「编辑资料」里可改 额度 / 有效期（日历）/ 备注 / 标签。

## 4. 群收款 `aa_*`（含发起人自己）

| 说这句 | 结果 |
|---|---|
| `我和王五群收款 300 元` | 300 元 ÷ (1 人 + 我) = 每人 150，**我承担 150、待收 150** |
| `向王五和赵六群收款 300 元` | 300 ÷ 3 份 = 每人 100，我承担 100、待收 200 |
| `发起群收款` | 弹卡面（金额/备注/参与人自己填） |
| `王五 100 赵六 200 一起群收款` | 按人金额（我承担 0，待收 300） |

群收款卡面能做：

- **金额**（含我总额）· **备注（事由）**
- **修改参与人**：展开后逐行「删除」、多选「添加所选」、「全选」、**＋ 新增收款人**（姓名+手机号）
- **均摊金额**大字（含我）· **按人设置金额**（可由你改每个人的应收）
- **发起群收款** → 同一张卡变「确认这一笔」（确认 / 取消 / 改金额）
- 办完自动清空，回到「＋ 新增群收款」

群收款相关：

| 说这句 | 结果 |
|---|---|
| `我的群收款有哪些` | 列表 + 付款状态卡（谁已付/未付） |
| `王五那 100 已经付了` | 登记已付（出确认卡） |
| `提醒赵六付群收款` | 提醒未付的人 |
| `把这笔群收款撤销` | 撤销 |

## 5. 演示主线（约 4 分钟，一路不回头）

```
① 我的收款人有哪些                    → 列表卡：5 人，白名单 2、普通 3
② 点开「王五」那一行                  → 展开详情：额度进度条、有效期、四个操作按钮
③ 给王五转 100 元                     → 白名单额度内 → L1 免码确认卡 → 确认 → 完成
④ 给张小美转 800 元                   → 非白名单 → L2 → 输入 123456 → 完成
⑤ 每个月末给房东转 500 元，到年底      → 循环卡（月末对齐、结束日 12-31）
⑥ 我的预约有哪些                      → 「循环」列：每月（至 2026-12-31）· 下次 …
⑦ 我和王五群收款 300 元                → 每人 150 / 我承担 150 / 待收 150 → 发起 → 确认
⑧ 我的群收款有哪些                    → 付款状态卡 → 登记已付 → 撤销
```
